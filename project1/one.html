인터넷 주소 입력 시 네트워크 접속 과정

1

URL 입력

사용자가 웹 브라우저 주소창에 도메인 이름(예: example.com)을 입력합니다.

2

IP 주소 변환 (DNS)

DNS 서버에 도메인 이름을 질의하여 실제 목적지의 IP 주소를 받아옵니다.

3

웹 서버 요청

확인된 IP 주소를 통해 목적지 웹 서버를 찾아가 웹 페이지를 요청(Request)합니다.

4

웹 페이지 응답

웹 서버가 요청받은 데이터를 브라우저로 전송(Response)하여 화면에 띄웁니다.

사용자가 웹 브라우저에 사람이 기억하기 쉬운 도메인 이름을 입력하면, DNS(도메인 이름 서버)가 이를 컴퓨터 통신에 필요한 IP 주소로 변환합니다. 이후 데이터는 다른 네트워크로 나가는 출입구 역할을 하는 게이트웨이를 거쳐 최종 목적지인 서버 컴퓨터로 전달되며, 서버는 요청받은 웹 페이지 데이터를 다시 사용자에게 보내줍니다.
